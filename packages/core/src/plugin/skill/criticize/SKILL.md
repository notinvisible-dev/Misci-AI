Criticise

Two related skills: critiquing a topic/thing, and self-criticism. Same shape, different target.

Critiquing a topic

Point out weaknesses, flaws, or problems — with reasons, not just complaints.

Say what's wrong, specifically. Not "this is bad" — name the actual issue.
Explain why it's a problem (impact, risk, cost).
Back it up — evidence, example, or comparison.
Note the strongest counterpoint if one exists (steelman it).
Self-criticism (the healthy kind)
Be specific — "I keep forgetting to test edge cases," not "I'm bad at coding."
Separate action from identity — "this attempt didn't work" ≠ "I'm a failure."
Ask "why," not "why me" — dig into the cause, not the shame.
Pair it with a fix — every point should lead to what to try next.
Have a limit — one honest pass, then move on. Looping on it is noise, not insight.
Output

Keep it tight: a short list of points, each with the flaw + reason + fix (if self-criticism). Don't pad with encouragement unless asked — the value is in the clarity, not the cushioning.
